# 자아성장연구소 정적 에셋 폴더 (Static Assets Folder)

이 폴더(`public`)에 웹사이트에 필요한 이미지 및 리소스를 직접 업로드하여 사용할 수 있습니다.

## 1. 프로필 이미지 업로드 방법
- 사용하실 프로필 이미지의 이름을 **`profile.jpg`** 또는 **`profile.png`**로 수정한 뒤, 이 `public` 폴더 안에 드래그 앤 드롭으로 업로드해 주세요.
- 코드에서는 자동으로 `/profile.jpg` (또는 `/profile.png`) 경로를 불러오도록 이미 설정해 두었습니다! 외부 링크를 쓰지 않고 이 폴더에 직접 업로드하시면 절대 이미지가 깨지지 않고 안전하게 유지됩니다.

## 2. 카카오톡 공유 미리보기 이미지 (Open Graph)
- 카카오톡이나 SNS로 사이트 링크를 보냈을 때 뜰 미리보기 이미지를 **`share-preview.png`** (또는 **`share-preview.jpg`**) 이름으로 업로드해 주세요.
- 권장 해상도: `1200 x 630 px` (가로:세로 약 `1.91:1` 비율)
- `index.html` 내부에 해당 미리보기 이미지에 관한 메타태그(OG Tag) 설정을 완료해 두었습니다.
